## 📖 About

**The Silent Love** is an original novel by Lijo Paul M E:

> *"Some love stories are written in words.  
> Others are written in silence."*

This web project transforms the original book manuscript into a production-ready, distraction-free digital reading experience with vector PDF fidelity.

---

## ✨ Features

- **High-DPI Vector Rendering**: Powered by PDF.js for crisp text rendering across Retina, desktop, tablet, and mobile screens.
- **Focus Reading Mode**: Distraction-free UI with soft-fading chrome controls.
- **Swipe & Touch Navigation**: Native mobile swipe gestures, chapter quick-drawers, and keyboard bindings.
- **Reading Position Persistence**: LocalStorage stores the active page index automatically.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Modern JavaScript (ES Modules), CSS3 Design System
- **Rendering Engine**: PDF.js v3.11
- **Persistence**: LocalStorage API
- **Typography**: Cinzel, Cormorant Garamond, Inter
